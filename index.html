Root-cause themes discovered

Unsupervised — no labels were given. The model independently rediscovered known issues (360 Savings rate practices) and surfaced operational defects from text alone.

Regulatory-lane triage classifier

TF-IDF + logistic regression routing each narrative to its regulatory lane (labels derived from the CFPB issue taxonomy; 80/20 stratified split; n=4,239 held-out). Production design: auto-route above the confidence threshold, human review queue below it.

Investigator Copilot — case walkthrough

Real dispute narratives run through the pipeline: case file → evidence inventory (extraction) → drafted response letter → deterministic citation validator. Every citation [E#] must resolve to an item in the inventory, or the draft is blocked.
Production architecture: the extraction and drafting layers shown here as deterministic templates are LLM calls in production (open-weight models in-house, per Capital One's platform strategy). The citation validator stays deterministic by design — zero-tolerance gates get engineering guarantees, not better model averages. A human investigator approves every output; nothing auto-sends.

The gate in action — corrupted draft

The same letter with one fabricated citation injected. The validator blocks it before any human sees it.
